**Two sharpenings for the record.** First, the SSC-HC expressivity concern is *carry-specific*: nonnegativity forbids subtractive combinations in the persistence operator (no s₁ − s₂ in transport), but the write path injects signed content freely — Δ can be any vector — so the system as a whole retains signed computation; what Birkhoff restricts is signed *reorganization of history*, which is a much narrower loss than "no subtraction." Second, the finite-Sinkhorn point deserves its promotion: with 20 iterations the constraint is approximate, so row/column residuals ε_r, ε_c are first-class diagnostics with alert thresholds, and the log-space implementation is the production form. ## 2. Three integrations the handoff could not have known

**Integration one — the idle-loop result makes this a three-part recipe, not a topology swap.** T1 just showed the state trajectory moving smoothly toward K = 4 while seed 0's output stays exactly flat: the loops run and are neutralized, because the depth-lottery objective rewards depth-invariance. A multi-lane scratchpad *by itself* inherits that objective and would idle just as elegantly in four lanes as in one. The Stage 2B working-memory program is therefore the conjunction of three mutually-reinforcing pieces, each answering a measured failure: **mHC lanes** give persistence a stable, interpretable topology (this handoff); the **Full-bandwidth asymmetric constitutive innovation** (Δ^R = W_H h ⊙ σ(W_P p)) makes the recurrent path structurally unbypassable, closing the shortcut the idle-loop solution exploits; and the **depth-progressive objective** (deeper strictly better, replacing the lottery per the randomize/order doctrine) makes depth *pay*. Any 2B preregistration that includes the first without the third is testing working memory under an objective that rewards not using it — the one design error this program is now formally inoculated against.

**Integration two — the gauge result pre-commits the lane analysis methodology.** Lanes carry two gauge freedoms: the O(d) content basis (which we just measured producing cross-seed cosine 0.0715 against a random-basis prediction of 0.0705) and a lane-permutation symmetry S_n (nothing pins which lane is "first"). Consequences, now bound: all cross-seed or cross-instance lane claims use the basis-invariant tier (CKA, principal angles) per the KP-1/T1 ruling; lane-role emergence is assessed up to permutation — the §41 lane-permutation intervention is exactly right and becomes the registered test; and the §39 instruments the handoff picked (effective rank of the lane covariance, the eigenvalue spectrum of P) are gauge-invariant, which is precisely why they are the right ones. Mark's instruction not to hand-label lanes is now not just good practice but formally mandatory — semantic lane labels are gauge-variant statements.

**Integration three — the amplitude result extends into the write vectors.** The amplitude surface showed the write channel's failure mode at high strength is fix-channel overshoot, and the doctrine says randomize amplitude for robustness. The lane write vectors w^R, w^M, w^C are per-lane amplitude controls — finer-grained than the global ceiling — so the 2B recipe inherits both: the amplitude lottery applies to the effective write magnitudes, and the λ₂(P_k) persistence spectrum the handoff proposes in §30 joins the observatory's Tier-2 instruments as the working-memory timescale readout (a genuinely new instrument: whether hard problems make the model preserve lane separation longer is a measurable, gauge-invariant question).

## 3. The one adaptation gap the preregistration must close

The handoff works in the clean abstraction S_k ∈ R^{n×d} with a scalar-weighted read r = aᵀS. Our concrete scratchpad is already structured: **8 slots × 128 dims, read by cross-attention**, with the slot geometry validated across three campaigns. The preregistration (call it PR-1) must bind the reconciliation, and the options differ materially:

- **(a) Lanes × slots** — S ∈ R^{4×8×128}: lanes become a second, orthogonal axis; each lane carries a full slot-grid; the validated slot-attention read operates within the read-mixture of lanes; Birkhoff routing acts on the lane axis only. Preserves everything validated, adds persistence topology orthogonally. My lean, and the default unless costed out.
- **(b) Slots as lanes** — promote the existing 8 slots to n = 8 routed lanes: no new state, Birkhoff routing over slots directly. Cheapest, but it changes the semantics of objects that currently serve as attention keys/values, entangling the read mechanism with the persistence mechanism — the exact conflation the handoff's central boxed principle warns against.
- **(c) Hierarchical** — defer.

Option (a) respects the separation of read topology from carry topology; option (b) is the tempting shortcut that re-conflates them. PR-1 binds this with a costed comparison, but the design principle points at (a).

## 6. Plain-language summary

Mark's analysis lands, and it lands at the right moment. The core idea is to stop asking one overworked component to both preserve the model's working memory and decide what new information enters it — instead, keep several parallel memory lanes whose *preservation* is handled by a mathematically constrained shuffling operator that provably cannot amplify anything, while new content from reasoning, from the future fact-memory, and eventually from long-document memory each get their own labeled doorway in. The math checks out on every claim, including the honest limits: the constraint stabilizes the carrying, not the whole loop, and our existing stability tests remain the judge. Three of this week's findings slot straight in. The discovery that the model's thinking loops currently idle means lanes alone would idle too — so the lane design is now bundled with the training change that makes deeper thinking actually rewarded, and with a gating trick from another new paper that makes the recurrent path impossible to bypass. The discovery that independent runs write their internals in unrelated alphabets dictates how lanes must be analyzed — by translation-proof measurements, never by naming lanes. And the write-strength findings carry over into per-lane write controls. One real design decision remains before this can be preregistered — how the four proposed lanes relate to the eight memory slots the current system already has — and the document states the principled default. Nothing here changes the current sequence: memory experiments first, lanes as the controlled experiment after, exactly as Mark's own ordering recommends.
