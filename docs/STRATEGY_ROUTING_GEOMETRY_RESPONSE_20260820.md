## 1. Source verification

All four citations are real and say what the note claims. **(1)** [arXiv 2605.12476, "Routers Learn the Geometry of Their Experts"](https://arxiv.org/abs/2605.12476): router weights for a selected expert and that expert's weights receive gradients along the same input directions, accumulating identical routed-token histories (theory + 1B-model empirics: higher router scores predict stronger expert-neuron activations); and yes, it demonstrates the parameter-free router — each expert maintains a running average of hidden states routed to it, assignment by cosine similarity — achieving the lowest load imbalance among balancing methods at modest perplexity cost. **(2)** [arXiv 2506.21328, "Latent Prototype Routing"](https://arxiv.org/abs/2506.21328): prototype routing framed explicitly as clustering, near-perfect load balancing. **(3)** [arXiv 2604.00801, "Routing-Free Mixture-of-Experts"](https://arxiv.org/abs/2604.00801): experts determine their own activation without a centralized router; early-stage, as flagged. **(4)** [arXiv 2407.04153, PEER](https://arxiv.org/abs/2407.04153): product-key retrieval over ~10⁶ tiny experts; expert selection as nearest-neighbor retrieval. The note's continuum — linear classifier → prototype → metric/kernel → subspace → large-scale retrieval — is a fair reading of where this literature is going.

## 2. Why this lands exactly on the 2B-D wound

The stop analysis located the collapse mechanism in **capacity-plus-sharing under a corpus-dominated loss**: one shared write module, receiving the summed gradient of a heterogeneous per-position correction field, converges to that field's common component — the corpus-prior direction — and applies it to every question. The seed-identical attractor (transitions matching to 0.005) is the fingerprint of a mean.

Routing is the architectural negation of that mechanism. A router partitions the correction field so each expert absorbs the mean of a *cluster* rather than the global mean: conditional computation converts "learn the one average correction" into "learn E different corrections plus an assignment function." If the corrections the questions actually need are multi-modal — math rows needing different steering than code rows than retrieval rows — then routed capacity can represent that structure where shared capacity provably cannot. This is not a generic architecture upgrade; it is aimed at the exact failure we measured. Mark's framing is the right one.

**The caveat, stated as a design law:** routing changes what the model *can* learn, not what it is *paid* to learn. Under the same corpus-dominated objective, a routed system has cheap collapse modes of its own — all experts converging to the same mean correction (expert homogenization), or the router sending everything to one expert (load collapse; the entire auxiliary-loss balancing literature exists because gradient pressure pushes there). The 2605.12476 coupling result cuts both ways: router and expert co-adapt to the same directions, so if the dominant direction is the corpus prior, the coupling *accelerates* collapse. Routing therefore enters the successor design **together with** the task-preservation anchor from the stop analysis (R3 mapping), never instead of it. The test I bound there applies verbatim to any routed objective: *does a question-independent policy achieve low loss?* If one expert filled with the corpus prior scores well, the router will find it.

## 3. Formalism review — four corrections and refinements

The note's math is sound in structure; four points need tightening before anything is bound.

**(a) The attention-derived "metric" is not a metric.** M = W_Q^⊤W_K is asymmetric and generally indefinite — it is a learned bilinear *energy*, fine for scores s_e = x^⊤Mc_e, but the Mahalanobis language (distances, geometry) requires symmetric PSD. Two clean repairs: symmetrize (M + M^⊤)/2 and clip negative eigenvalues, or use B = W_Q alone so M = W_Q^⊤W_Q ⪰ 0 exactly. The head-mixture variant s_e = Σ_h α_h x^⊤M_h c_e is unaffected (it's scores, not distances).

**(b) Wasserstein term sign.** The Gaussian W₂² trace term is Tr[Σ_t + Σ_e **−** 2(Σ_e^{1/2}Σ_tΣ_e^{1/2})^{1/2}] — the note's rendering dropped the minus. Content otherwise correct. Ruling: parked at Tier-2, diagonal covariances only (W₂² = ‖μ_t−μ_e‖² + Σ_i(σ_{t,i}−σ_{e,i})²), and noted that mHC lane statistics are a natural (μ, Σ) state if this ever runs.

**(c) Self-routing is the moving-geometry loop in its purest form.** Routing by the expert's own top right-singular vectors is elegant (s_e = ‖V_{e,r}^⊤x‖² reads "how sensitive is this expert to this state"), but it closes the tightest possible feedback loop: weights → routing → data assignment → gradients → weights. That is the note's own §10 instability diagram with zero damping. Queued as a late ablation, never the base design.

**(d) The gauge finding picks the router family for us.** Our cross-seed result (core cosine 0.0715 ≈ the √(2/π·128) random-rotation prediction) says learned features live in seed-specific bases. Gradient-trained prototype vectors are gauge-*dependent* objects — they mean nothing across seeds and drift within a run as the representation rotates. But the **online-centroid router is gauge-covariant by construction**: running means of the model's own states are automatically expressed in the model's own current basis, and cosine/Mahalanobis/subspace-occupancy scores are relational. The parameter-free router isn't just cheaper — it is the one member of the family that is well-posed under our measured gauge freedom. Same logic makes CKA/permutation-invariant metrics the only legitimate way to compare expert specialization across seeds, exactly as the mHC memo already binds.

Two house alignments come free. The **frozen-substrate law already outlaws regime A**: routing gradients cannot flow into any substrate matrix (bit-exactness is a hard gate), so q = sg(W_Q x) — regime B — is not a design choice for us, it is the law, and regime C (small trainable B over a stop-gradded substrate projection) is the only trainable option touching substrate geometry. Mark's instinct to start at B/C is our mandatory starting point. And **velocity routing is uniquely ours to exploit**: an ordinary MoE routes on h_t alone; our K-loop recurrence exposes (h_k, h_{k−1}, b_k, Δb_k) at every step, so the router can condition on *what the reasoning trajectory is doing* — which is precisely the query-dependent signal whose absence let the shared write collapse to a query-independent attractor. The K1→K4 margin geometry we just measured is itself a velocity signal that a router could have seen.

## 4. The free experiment, authorized now: correction-field clusterability (2B-A rider, arm 6)

Before any router is built, the preserved 2B-D checkpoints let us answer the prior question at zero training cost: **does the correction field routing would partition actually have clusters?**

Protocol (score-only, rides the 2B-A session): at the init checkpoint, over a stratified DEV sample (per battery), collect per-row correction directions — the gradient of the per-row loss with respect to the write-path output (or equivalently the teacher-implied residual correction) — and test multimodality: k-means silhouette and Gram-matrix eigengap versus label-shuffled and rotation-null controls; report cluster–battery mutual information. Two pre-registered readouts. **(i) Clusterability:** eigengap/silhouette significantly above nulls → routing has real structure to find → the routed successor is justified; a unimodal field → routing cannot help and the successor leans entirely on the objective repair. **(ii) The mean-field confirmation:** cosine between the *trained* 2B-D write direction (stop checkpoint) and the *mean* of the init correction field. The stop analysis predicts this cosine is high — that single number would convert the corpus-prior-collapse account from strongly circumstantial to directly measured, and it costs one dot product on artifacts we already have.

## 6. Plain-language summary

Mark's proposal arrives at the perfect moment. Last campaign's failure had a precise shape: one shared steering module, asked to help with a million different situations, learned the *average* correction — which helps no one. A mixture-of-experts router is the standard cure for exactly that disease: instead of one module learning one average, several small experts each learn the average of their own neighborhood, and a dispatcher sends each situation to the right one. His deeper point survives scrutiny too: the dispatcher doesn't have to be the usual learned classifier — it can measure similarity in a geometry the network already has (its attention coordinates, its statistical shape after correcting for known distortions), or maintain simple running averages that need no training at all. That last option is especially attractive for us because our own measurements show each trained copy of the model speaks its own rotated internal language, and running averages automatically speak the right one. Two cautions keep us honest: a dispatcher can also collapse — sending everything to one expert, or letting all experts learn the same thing — so this rides alongside, never instead of, the fix from the stop analysis (pay the loops for keeping the question alive). And before building anything, one free measurement on the saved checkpoints tells us whether the corrections the questions need actually come in distinguishable families — if they don't, no dispatcher can help; if they do, we'll also get a single number that directly confirms why the last run failed. The full router bake-off is designed, adopted, and queued behind the autopsy.
