# Program Track: Master Sequence

**Canonical date:** July 15, 2026

Part 1, deterministic recurrent-depth Qwen, is closed. The active program is now a gated transition from a frozen deterministic keeper to guided stochastic width.

## 1. Destination

The destination remains a compact reasoning model that uses:

- recurrent latent depth for sequential composition;
- learned stochastic width when a task admits multiple valid solutions;
- a selector only after diverse trajectories contain additional correct solutions;
- controlled comparisons against dense models from the same family.

Part 1 established the deterministic substrate on controlled tasks. It did not establish broad natural-benchmark superiority or useful latent width.

## 3. Standing Rules

### Keeper protection

The clean deterministic checkpoint is a `frozen_asset`. It cannot be replaced by a full-block continuation. Capability-bearing adaptation must use detachable heads or adapters.

Full-block training is allowed only as a `disposable_measurement`. It is non-promotable, cannot become successor lineage, and must carry its own guardrail hard stop.

### Launch assertions

Every training launch must resolve and print:

- exact source checkpoint path and SHA-256;
- source receipt path and metric values;
- every registered floor and pass/fail result;
- trainable parameter groups;
- output lineage policy.

The launcher fails before model loading when any assertion fails.

### Decision discipline

Parallelize between decisions, never through them. No job launches before a gate that determines whether the job is authorized. Results are scored against locked gates before successor design.

## 4. Active Sequence

### Step A: final non-gating deterministic localization. Completed, inconclusive.

Run the loop-position transfer micro-test as a disposable measurement.

- Train inverse placement only at loop positions 1 and 2.
- Evaluate zero-shot placement at positions 3 and 4.
- Interpret both transfer positions `>=0.55` as substantial position invariance.
- Interpret both `<=0.15` as per-position installation.
- Treat intermediate results as partial transfer.

The trained-position prerequisite passed at step 500, but the step-1,000
synthetic guardrail fell to `0.8125 < 0.93`. The hard stop fired before transfer
positions 3-4 were measured, and the disposable checkpoints were deleted.
Nothing downstream depends on this inconclusive result.

### Step B: width-substrate screen. Completed, passed on N20 verbal.

Evaluate a multi-valued forward-relation task with exact reachable sets:

- N20 verbal rows on the natural-surface keeper;
- N24 symbolic rows on the N24 keeper;
- depths 1-4, 128 frozen rows per depth;
- pooled exact validity `>=0.70`;
- every depth exact validity `>=0.55`.

The natural N20 verbal keeper passed at `389/512 = 75.98%`, with every depth
above the `0.55` floor. The N24 symbolic keeper missed at
`355/512 = 69.34%`, including depth 3 at `52.34%`. One keeper is green, so no
adapter touch-up is needed.

### Step C: Phase G-alpha guided latent width. Active.

First perform the power calculation and fill the only remaining numeric blank
in the preregistration. Then freeze the natural step-2,000 keeper and train only:

```text
phase_g_prior_head.*
phase_g_posterior_head.*
phase_g_injection_scale
```

The posterior conditions on a stored sampled valid chain during training. Inference samples independently from the learned prior. Stochasticity enters only at the high-level re-entry state.

Mandatory assertions:

- exact `K=1` parity with the deterministic keeper when injection is disabled;
- zero gradients on every frozen parameter;
- no target fields in the inference prior path;
- independent RNG streams and durable per-trajectory manifests;
- exact reachable-set validity and coverage scoring.

Primary paired comparators:

1. entropy-matched answer-head sampling at matched K;
2. one deterministic trajectory at matched `K*T` transition compute.

G-alpha passes only if guided latent trajectories beat both comparators under the powered, preregistered margin.

### Step D: G-beta selection and adaptive width

This step is closed unless G-alpha passes. If opened, it may test:

- a latent process reward model or claim-level selector;
- per-trajectory halting;
- calibration and selector reliability on held-out rows;
- SVGD strictly as an ablation against independent prior sampling.

The success metric is conversion of newly covered valid solutions into selected-answer accuracy, not raw diversity.

### Step E: scale and external capability

Only after the mechanism survives the small-model gates:

1. port the architecture and data contracts to Qwen 1.5B or 3B;
2. run matched dense and recurrent training recipes;
3. evaluate external hard-tail benchmarks with frozen prompts and exact scoring;
4. publish a checkpoint only after natural-benchmark, guardrail, and reproducibility gates pass.

The code must remain model-size modular. The scale decision is explicit because particle width multiplies inference cost.
