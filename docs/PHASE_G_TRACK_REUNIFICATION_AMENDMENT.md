## Decision

The deterministic substrate program and the original stochastic-width program are one dependency chain. Width is not measured on single-valued tasks. The abductive-injective gate therefore serves two roles: it is the next deterministic block-training rung and the substrate gate for the first attributable GRAM-style width experiment.

Early particle/noise negatives remain evidence about those specific implementations only. They predate the repaired loop closure and did not implement a target-conditioned posterior. They do not test guided stochastic trajectories.

## Amended Queue

1. Finish the transfer-consolidation receipts without GPU work.
2. Complete the deterministic injective and mixed abductive task gate with the synthetic guardrail.
3. Evaluate that keeper on the arbitrary N=24 calibration split. If it fails basic deterministic validity, run one bounded deterministic arbitrary-table continuation before freezing it.
4. Run Phase G-alpha before inductive, PrOntoQA, or rung-one paraphrase work unless spare budget allows those in parallel.
5. Resume those breadth tasks after G-alpha.
6. Open G-beta only if G-alpha improves exact oracle coverage over both locked comparators.

The deterministic paper remains first. Its characterized substrate is what makes the width result attributable.

## Locked G-alpha Architecture

- Freeze the complete deterministic recurrent-Qwen substrate.
- Train only the prior head, posterior head, and scalar injection scale.
- Inject only at the high-level re-entry state.
- Leave the deterministic update unchanged.
- Condition the posterior at every transition on the gold next symbolic state. For multimodal rows, generate and store one uniformly sampled valid chain.
- Use per-loop task loss and per-loop posterior-to-prior KL, KL balance `0.8`, EMA, and a small locked KL-coefficient sweep.
- Assert the frozen block has no trainable parameters and exactly zero gradients after every backward pass.
- Keep fixed depth during G-alpha. Learned per-trajectory halting, LPRM selection, and SVGD are deferred.

The implementation-level specification is [PHASE_G_ALPHA_GUIDED_STOCHASTIC_TRANSITION_SPEC.md](PHASE_G_ALPHA_GUIDED_STOCHASTIC_TRANSITION_SPEC.md). The machine-readable contract is `training/phase_g_alpha_spec.py`.

## Frozen Evaluation

The final claim set uses arbitrary non-bijective functions over `N=24`, depths `1-4`, and two disjoint splits:

- calibration;
- test.

Each split contains `128` rows in each exact-preimage stratum:

- unique: exactly `1`;
- small: `2-4`;
- large: `>=5`.

Every row stores the complete preimage set, but the scorer independently recomputes it by applying the forward map from all 24 starts. The stored set and denominator must match or evaluation aborts.

The currently running deterministic screen uses the earlier constructive N=20 fan. Its row hashes remain locked and its result remains useful, but it does not by itself establish competence on arbitrary N=24 tables. G-alpha opens only after the resulting keeper also clears the arbitrary calibration distribution. If it does not transfer, the required repair is deterministic training on independently generated arbitrary tables, not stochastic-head training.

## Locked Gate Forms

Primary outcome: paired per-instance exact oracle coverage at `K=1,2,4,8,20`.

Comparator 1: deterministic keeper answer-head sampling at matched `K` and matched per-instance categorical entropy. Fixed-temperature output is provisional and cannot decide G-alpha.

Comparator 2: one deterministic trajectory at depth `K*T` versus `K` independent trajectories at depth `T`, matched on recurrent-transition count.

Statistical form: paired tests on identical frozen rows, alpha `0.05`, stratified by exact preimage-set size. The numeric effect margin is the only preregistration blank and is locked from a power calculation on the calibration split before the test split or guided latent result is scored.

## Pre-written Readings

- No win over entropy-matched answer sampling: guided latent width adds nothing beyond output sampling on this substrate.
- Win over answer sampling but loss at iso-compute: width exists but is uneconomical relative to depth.
- Win over both: G-beta opens.

A negative is not accepted until the preregistered KL-coefficient and training-dose levers have been exercised.

## Lineage

This amendment supersedes the old separation between deterministic work and an eventual return to stochastic width. It does not change guardrails, checkpoint hash requirements, the deterministic paper order, or the G-beta gate.
