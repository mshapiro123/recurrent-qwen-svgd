## 2. Section-9 decisions (Mark/strategy, 2026-08-03)

1. **Radius: c = 0.15 with the p99 RMS cap**, not conservative c = 0.10. Rationale: the cap removes the measured harm carrier (1 percent of positions, 38.5 percent of harms) while retaining 12.5 points of reach that a global c = 0.10 would forfeit; the tail, not the radius, is the risk.
2. **V1d is required before E1 lock**: the identical corrected protocol on the same cohorts with the cap applied, reporting realized reach, collateral, and preserve retention after capping. Capping changes realized radii; reach-after-cap is measured, not inferred. DEV-only, no training.
3. **Preservation criterion: preregistered non-inferiority margin, two-tier by sample size** (revised per Mark, 2026-08-03 — a 99.5 percent CI floor at n = 2,000 is nearly as brittle as exact-zero, since a 99.8 percent point estimate's Wilson lower bound is only ≈ 99.6 percent). Diagnostic scale (V1d, n = 2,000): point ≥ 99.7 percent with 95 percent CI lower bound ≥ 99.0 percent — the point estimate binds; the CI guards flukes. Confirmation scale: preservation measured over the full frozen-slice baseline-correct population (n ≈ 150k, CI width ≈ ±0.02 percent), margin set at E1 lock against the actual n. Exact-zero retention is retired at every scale.
4. **Gate features, with the oracle-feature correction**: sequence position enters the sidecar gate features from the first E1 build (deployable, cheap, measured signal). The first-order distance is an *oracle* quantity (it requires the teacher token) — it becomes a training-time curriculum weight and a preregistered evaluation stratification, never an inference input. V3's probe battery gains one named question: how much of the oracle-distance signal is recoverable from deployable proxies (student margin, entropy, state features, position). That answer sizes the gate's realistic selectivity.
5. **E4 remains deferred** pending V1d, per the coding recommendation.

## 5. Plain-language summary

The bigger-nudge experiment worked: at the largest tested setting, the perfectly aimed correction fixes about six in ten target mistakes, and the danger turns out to live almost entirely in a tiny population of unusual hidden states — about one percent — which a simple cap removes. So we take the larger setting plus the cap, and run one last cheap check (V1d) to confirm the capped version keeps most of the reach. Preservation switches from "never lose a single case" to a strict statistical margin, because at these scales single unlucky cases shouldn't decide verdicts. Meanwhile the new v0.5 design adds a mathematically careful way to compress the big teachers' internal states into a small, well-behaved target space and to walk the student's scratchpad toward those targets step by step — always measuring each step from where the student actually is, never leaking the answer into the student's inputs. That same never-leak, measure-from-where-you-are principle now governs every part of the training design, which is exactly the principle our failed experiments taught us.
