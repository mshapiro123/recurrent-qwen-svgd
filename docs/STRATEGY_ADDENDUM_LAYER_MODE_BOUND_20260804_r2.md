**Revision r2 (2026-08-04), supersedes Drive `1R65rFizDLhXfdfo3TDGy1tLhWyJY5chG` — fit method corrected per the coding agent's cost flag, which strategy verified and extends.** The r1 deterministic-LAPACK requirement was wrong twice: the dense 15,360² decomposition is ≈ 3.6e12 flops (the coding agent's point, correct), and forming the covariance at all is worse — N·n² ≈ 166,708 × 15,360² ≈ 4e13 MACs, an order of magnitude above the decomposition and the true dominant cost. The randomized sketch never forms the covariance (streamed passes over X at ~N·n·k each), which is exactly why the 5,120-dim fits were fast; concat merely triples that. r2 therefore reverts to the arbitration's own proven protocol — randomized fits, three common seeds, spread audit — at ≈ 3× the prior per-fit cost, comfortably one CPU session.

## 1. The question, reduced

With three teacher layers, the layer mode has dimension 3, and the current canonicalizer applies one shared learned mixture vector — layer-mode rank 1. True Tucker's entire potential contribution in this setting is layer-mode rank above 1: different canonical coordinates drawing on different layer combinations (blends and contrasts) instead of one shared blend. The structure ladder is strict: rank-1 mixture ⊂ Tucker (layer-rank 2 or 3) ⊂ concatenated-layer RRR (unrestricted). Concatenation therefore upper-bounds everything Tucker could add, and one concatenated fit answers the question without implementing Tucker.

## 2. Authorized experiment (CPU, cached states, before pilot launch)

**Arm: `concat_rrr`** — the same predictive RRR fit, same targets Y, same rank r_c = 256, same whitening contract, on the stacked three-layer input (3 × 5,120 = 15,360 dims, per-layer RMSNorm retained before stacking). **Fit method (r2): the arbitration's own protocol** — randomized low-rank SVD on streamed passes over the design matrix (never materializing a 15,360² covariance), the same three common seeds `{20260814, 20260824, 20260834}`, per-arm seed-spread audit. Expected cost ≈ 3× the prior 5,120-dim per-fit cost (pass cost scales with n), one CPU session. **Spread gate**: the maximum within-arm agreement range must be below **0.25 points** — half the swap bar — for the comparison to be decision-grade; if the spread exceeds that on the wider problem, report it and stop, and the swap branch expires on noise grounds (the bound is then quotable only with its uncertainty). Evaluation identical to the arbitration: teacher top-1 agreement primary, future KL secondary, document-disjoint holdout, paired row-level bootstrap 10,000 replicates, both strata reported. Comparator: the existing `learned_mixture_rrr` fits under the same three seeds (already on file from the arbitration — no refit needed). One caveat carried honestly: a shared seed does not cancel sketch noise across differently-shaped problems (15,360 vs 5,120 inputs), which is precisely why the spread gate, not seed matching, is the noise control here.

**Preregistered decision rule — the bar to unlock a locked decision is deliberately high:**

1. If the paired 95 percent CI lower bound on Δagreement (concat minus learned-mixture) is **≥ +0.5 points** with consistent sign across strata: the canonicalizer swaps to `concat_rrr`, the freeze set re-hashes, and the pilot protocol's canonicalizer hash updates before launch — a one-hash amendment, no other protocol change. In this branch only, a follow-on Tucker layer-rank-2 fit is authorized as the parameter-efficient middle point, nonblocking.
2. If the CI lower bound is below +0.5 points: **`learned_mixture_rrr` stands**, the measured bound is banked, and the true-Tucker question is closed permanently with the manuscript sentence it earns — layer structure beyond a rank-1 learned mixture adds at most the measured amount on this substrate.
3. Overfitting guard: concat triples input dimension at fixed r_c; the holdout is the arbiter as always, and calibration-vs-holdout gap is reported alongside (a large gap with a holdout win still satisfies rule 1 — the rule is holdout-based — but the gap is recorded for the paper).

## 3. Sequencing

This slots before pilot launch and must not delay it materially: under the r2 method the job is ≈ 3× the arbitration's per-fit cost (CPU, cached, no GPU). If it cannot run before the protocol commit for any practical reason, the pilots launch on `learned_mixture_rrr` as locked and rule 1's swap branch expires — the bound is then computed nonblocking and, if it would have fired, that fact returns to strategy as a v2 consideration rather than a pilot invalidation. Position-mode Tucker structure (across boundaries) is explicitly out of scope: the evidence pointing at layer structure is the mixture win, and the boundary mode is already handled by per-horizon targets.

## 4. Plain-language summary

We thought we had tested a fancier decomposition and found it barely helped; it turned out we had actually tested something simpler — one shared recipe for blending the teacher's three layers — and that the blend itself was the real winner. The fancier method's only possible advantage here is letting different parts of the compressed state use different blends. There is a one-shot way to measure the ceiling on that advantage: feed all three layers in unblended and let the fit use them freely. If that ceiling is low, the fancy method is dead forever at near-zero cost. If it is high, we switch to the free-form version before the training pilots start — and only then is the fancy middle ground worth building. Either way the question Mark raised gets a definitive, cheap answer instead of lingering. (One correction along the way: the first version of this plan asked for an exact matrix decomposition to eliminate randomness, but the coding agent caught that the exact route is far more expensive than estimated — and the bookkeeping shows even assembling its input is the real bottleneck. So the test reuses the fast randomized recipe that just settled the mixture question, with a strict noise budget: if the randomness measures more than half the bar a challenger must clear, the test declares itself inconclusive rather than pretending precision it doesn't have.)
